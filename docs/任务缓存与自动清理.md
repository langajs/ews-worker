# 任务缓存与自动清理

## 保留规则

- 任务数据和 `ews/{task_id}/` 下的 R2 对象作为 7 天临时缓存。
- 完成任务从 `completed_at` 开始计算；其他状态从 `created_at` 开始计算。
- 到期任务不再出现在任务列表，任务操作返回 HTTP 410。
- 工作流对到期任务的上传票据或回调请求会收到 `retryable: false`。

## 自动清理

- Cloudflare Cron 每 6 小时检查一次清理状态。
- 距离上次完整清理达到 72 小时才启动新一轮清理。
- 每批最多清理 20 个任务；存在积压时每 6 小时续跑，直到清空后记录成功时间。
- 每个任务先幂等删除 R2 前缀，再用 D1 `batch()` 原子删除任务关联记录。
- R2 失败时保留 D1，供下一轮重试，避免不可追踪的对象残留。

## 管理接口

`POST /api/admin/task-cleanup` 仅管理员可调用。

```json
{
  "execute": false,
  "limit": 20
}
```

`execute=false` 只返回到期任务；`execute=true` 立即执行一批并绕过 72 小时检查。执行生产清理前必须先记录 D1 Time Travel bookmark。
